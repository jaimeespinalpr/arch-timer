# Branding assets (drop-in)

Pon tus imagenes aqui con estos nombres para que la web las use automaticamente:

- `logo-full.png`: logo horizontal para la pantalla de edicion (header/logo grande).
- `logo-mark.png`: logo cuadrado o isotipo para la barra superior del timer.
- `watermark.png`: imagen de fondo/transparente para el centro del timer.

Si alguno no existe, la app usa las imagenes actuales como fallback.

## Recomendado

- `logo-full.png`: PNG transparente, ancho aprox. `800px` (horizontal).
- `logo-mark.png`: PNG transparente, `512x512`.
- `watermark.png`: PNG transparente, `1200px` de ancho o mas.

## Nota

- Usa fondo transparente (`.png`) para que se vea mejor con los colores del timer.
